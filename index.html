Made to Order

You ask. It gets made. Every single day.

Made to Order is a YouTube channel with an unusual rule: the audience decides what gets made next by leaving a comment. It is at @madetoorder-z6y on YouTube.

How it works

  1. Each video asks viewers to leave a request in the comments.
  2. Every comment is read. One request from one person becomes the next video. When many people ask for the same thing, that shared request becomes the next video instead.
  3. The request is turned into a short animated explainer and published the following day.
  4. Every eligible request ends up made, queued, or declined with a stated reason. Nothing is dropped silently.
  5. When no request is waiting, the channel explains one thing it found itself — an item from a named outlet, credited and linked on screen. Nobody is credited with asking for it, because nobody did.

What this application does

This site is the home page for the software that runs that channel. The software is a private, single-user automation. It connects to exactly one YouTube channel — its own — using the YouTube Data API v3, and it:

  • reads the public comments left on that channel's own videos;
  • publishes that channel's own videos; and
  • posts a public reply on the channel's own videos when a request has been fulfilled.

It does not act on any other channel, and it has no other users.

Everything the automation does is published openly on the channel, including the channel's selection rules — and a permanent ledger of every request it has received and what happened to it.
